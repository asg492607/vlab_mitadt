# NetForge VLab — Spec (Local-Only)

NetForge VLab is a browser-based networking lab simulator inspired by Cisco Packet Tracer workflows.

## Views
- Logical View: topology canvas, devices, cables, simulation timeline.
- Physical View: device “rack” cards with ports and services.

## Modes
- Real-time: simulation engine processes queued events continuously.
- Simulation: events are queued; user steps PDUs.

## Import/Export
- Export: downloads a single-file `.nfz` containing the project JSON.
- Import: loads a `.nfz` back into the app.

## Evaluation
- Labs provide checks and scoring. Reports export as JSON.
