# Security Policy for MIT ADT VLAB

## Supported Versions

We are committed to maintaining a secure environment for students and educators. Security updates are prioritized for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within the MIT ADT VLab platform, please report it to our core development team.

**Core Security Team:**
*   **Supervisor**: Dr. Nilesh Thorat
*   **Lead Developers**: Atharva Gandhi & Nayan Solanki

**How to Report:**
1.  **Email**: Send a detailed report to the team at `atharva.vlab@mitadt.edu` or `nayan.vlab@mitadt.edu`.
2.  **Confidentiality**: Please include "VULNERABILITY REPORT" in the subject line to ensure immediate escalation to Dr. Nilesh Thorat.
3.  **Details**: Please include a description of the vulnerability, steps to reproduce, and any potential impact.

**What to Expect:**
*   **Acknowledgment**: You will receive an acknowledgment of your report within 48 hours.
*   **Updates**: We will provide weekly updates on the status of the investigation and fix.
*   **Resolution**: Once a fix is verified, we will coordinate the disclosure with you.

We appreciate your help in keeping MIT ADT VLab secure!
