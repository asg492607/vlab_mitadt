Transmission Control Protocol

Aim

To understand the working of Transmission Control Protocol (TCP) and its flow control mechanisms like Stop and Wait and Go-Back-N (GBN).

Theory

Introduction to TCP

TCP (Transmission Control Protocol) is one of the main protocols of the Internet Protocol Suite. It originated in the initial network implementation in which it complemented the Internet Protocol (IP). Therefore, the entire suite is commonly referred to as TCP/IP.

Flow Control Mechanisms

Stop and Wait

The sender sends one packet and waits for an acknowledgment (ACK) from the receiver before sending the next packet. If the ACK does not arrive within a timeout period, the sender resends the packet.

Go-Back-N (GBN)

The sender can send multiple packets (up to a window size N) without waiting for an ACK. If a packet is lost, the sender resends all packets starting from the lost packet.

Question 2: In Stop and Wait protocol, what happens if an ACK is lost?

A) Sender waits forever

B) Sender resends the packet after timeout

C) Receiver requests the packet again

D) The connection is closed

Procedure

  1. Navigate to the Simulation tab in the sidebar.
  2. Select the protocol type: Stop and Wait or Go-Back-N.
  3. Observe the Sliding Window indicator on Host A to see active packets.
  4. Watch the Timer Bar above Host A; if it reaches 100% without an ACK, a timeout occurs.
  5. Click on a moving Packet (blue square) with Shift + Click to simulate network loss.
  6. Observe how the Go-Back-N protocol resends all unacknowledged packets from the base of the window after a timeout.
  7. Check the Event List for detailed timing and protocol logs.
